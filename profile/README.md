# HistoForge

**AI for histology, in QuPath.**

An open-source platform for histology image analysis. Use community models to
identify cells and tissue structures, get measurements, and train and share
models using your own annotations. Analysis and training run in your cloud account.

[Website](https://histoforge.github.io/) ·
[Documentation](https://histoforge.github.io/docs/) ·
[Modules library](https://huggingface.co/models?other=histoforge)

For code or documentation contributions, use the relevant repository's issues and
pull requests. To discuss contributing a dataset or model, email
[histoforge.contact@gmail.com](mailto:histoforge.contact@gmail.com).

HistoForge is not intended for clinical, diagnostic or therapeutic purposes.
